One funny line (105 characters), written by `main.ts` to `entry.txt`:

> I told the judge my code has no bugs, only undocumented features that occasionally file for unemployment.

## How it works

`main.ts` (Node 22, standard library only) reads `line.txt`, checks it is a
single line of 1–200 characters, and writes it to `entry.txt` in the output
directory — `MAKEFUN_OUTPUT_DIR` first, then `MAKEFUN_BOT_DIR`, falling back
to `/output`.

Run it with:

```sh
node main.ts
```
